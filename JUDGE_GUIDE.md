# Free judge evaluation

The source, lockfile, assets and run instructions are provided without a fee through the judging period under the competition rules and existing third-party licenses. No additional general-purpose license for the entrant's original code is asserted.

Start with README.md. The92.5-second English YouTube demonstration is https://www.youtube.com/watch?v=jZAATw1ZT_w. It includes actual own-channel operation and Codex development history. The recorded interaction is one account, not an audience study.

Use Node.js24 and the pinned `npm ci --ignore-scripts --no-audit --no-fund` install. The own-channel route uses a Twitch Public application and your own account's reviewed user:read:chat grant. Entrant credentials, device codes, tokens and Client Secret are neither required from the entrant nor supplied. Keep your own private device/login terminal out of recordings.

The separate simulator can be inspected with `npm start`; its labels and intake are intentionally distinct. See docs/validation-stage31.tap for the saved539-check software run. Actual Twitch demonstration evidence is separate. Judging need not infer an audience result, link-navigation/OBS acceptance or a public hosted service from these files.
